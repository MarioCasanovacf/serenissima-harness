# Mario profile activation

Treat `personal:mario` as an explicit secondary profile layered onto the selected operating mode.
Activate it only when the request or project instructions contain that exact flag and the artifact
is Mario Casanova's portfolio work, personal presentation, authored case study, report, or page.

Do not infer activation from Mario's name, an artifact being personal, a paper-like reference, or
the presence of this skill. Without the flag, do not import Mario's typography, palette,
materiality, voice, layout rules, or exclusions. Stay brand-neutral and do not default to a light
paper surface. If the flag conflicts with a supplied brand or product contract, preserve the
contract and ask one focused question rather than blending identities.

State both the primary mode and `profile: personal:mario` in the design read. Before delivery,
verify that Mario-specific choices appear only in flagged outputs and that an equivalent no-flag
request contains no Mario identity, token set, signature type stack, or paper-and-ink assumption.
