# Production Preflight

Run every applicable check before delivery. Fix failures and disclose checks the environment could
not execute.

## Brief, mode, and integrity

- [ ] The primary mode and design read are explicit and supported by the brief.
- [ ] Every requested deliverable was enumerated before implementation and is complete or has an
  explicit, justified exception.
- [ ] Assumptions are distinguished from evidence; no facts, proof, data, or assets are fabricated.
- [ ] The existing framework, package manager, design system, data and API contracts, state
  semantics, routes, forms, analytics, consent, legal behavior, accessibility, SEO, content
  meaning, tests, and budgets are preserved unless an authorized change is documented.
- [ ] Preserve or overhaul scope and before/after contract checks are recorded for redesigns.

## Interface quality

- [ ] Purpose, state, hierarchy, and primary next action are clear.
- [ ] Type, color, spacing, grid, icons, radii, borders, shadows, imagery, and motion form one
  coherent system rather than a collection of trends.
- [ ] Real content extremes, long labels, missing data, localization, and applicable product states
  do not break the design.
- [ ] Marketing evidence is authentic; dashboard units and freshness are clear; transactional
  totals, consequences, validation, progress, and recovery are correct where applicable.

## Accessibility and interaction

- [ ] Landmarks, headings, reading and focus order, labels, alt text, contrast, zoom, touch targets,
  keyboard use, screen-reader state, and visible focus meet project policy.
- [ ] Applicable hover, active, disabled, loading, partial, empty, stale, offline, permission,
  error, retry, success, and destructive-action states work.
- [ ] Motion has a user-facing purpose, remains interruptible, preserves content, honors reduced
  motion, and cleans up observers, listeners, frames, and timelines.

## Responsive, performance, and verification

- [ ] Representative narrow mobile, wide mobile, tablet or intermediate, laptop, and large widths
  have no unintended overflow, clipping, hidden actions, broken reading order, or unusable data.
- [ ] Images reserve space and use sensible formats, sizes, crops, and responsive sources. Fonts,
  scripts, animation, hydration, and media stay within project budgets.
- [ ] Relevant lint, type, unit, integration, build, accessibility, and browser or render checks
  pass with a nonzero executed count where counts apply.
- [ ] Visual comparison covers the critical screens, states, and supported themes.
- [ ] The delivery report names verification performed, intended contract changes, placeholders,
  known deviations, and unverified risks.
- [ ] Placeholders exist only for truly missing external assets or dependencies and each states its
  dimensions, role, and replacement next step.
